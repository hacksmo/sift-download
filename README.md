# Sift · 安装包下载

**中文** · [English](README.en.md)

[Sift](https://sift.hackmo.net/) 是给剪口播视频、做自媒体配图的人用的 Mac 本地找图工具：说一句中文，几秒从本地几千张素材里精准找到那张图，直接拖进剪映。AI 大模型完全在本机离线运行，素材一张都不上传。

这个仓库**只用来存放安装包**，源码与官网不在公开仓库。

## 下载

点右侧 **Releases** → 最新的 `Sift-x.y.z.dmg`。

或直接访问最新版：<https://github.com/hacksmo/sift-download/releases/latest>

## 安装

1. 下载 `Sift-x.y.z.dmg`，双击打开
2. 把 `Sift.app` 拖进「应用程序」文件夹
3. 首次打开会被系统拦下（当前为 ad-hoc 签名、未做 Apple 公证）：到「系统设置 → 隐私与安全性」，在页面底部点「仍要打开」；或右键点 App 图标选「打开」。确认一次即可，之后正常双击启动
4. 首次启动会引导导入中文语义模型（约 720 MB，可选；不导入则回落到文件名与 PDF 正文检索）

## 系统要求

- Apple Silicon Mac（M1 及以上）
- macOS 14 Sonoma 或更新
- 不支持 Intel Mac、Windows、Linux

## 隐私

索引库、向量、缩略图全部保存在本机应用数据目录；没有账号、没有云端同步、不上传任何素材，断网照常用。
